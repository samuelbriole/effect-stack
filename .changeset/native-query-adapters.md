Add first-party Query adapters with typed application context, explicit Atom registry ownership, reactive optional resource
subscriptions, and invocation-specific mutation bridges. React activates query subscriptions at commit, while Solid and
Vue follow their native reactive lifecycles. Expose Effect and typed Exit APIs alongside awaitable event-handler methods,
preserving the scoped core client's cache and mutation ownership.
